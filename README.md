## About

D. Ware HQ is my portfolio site for documenting hands-on work across cybersecurity, networking, software development, AI, research, and technical leadership.

The site is intentionally lightweight and built without a frontend framework so the focus stays on the work itself, accessibility, and a fast static deployment through GitHub Pages.
